# Revo Coffee - Мобильный интерфейс

## 📱 Описание проекта
Адаптивный сайт кофейного магазина Revo Coffee с полноценной мобильной версией, созданный согласно требованиям **Практического занятия 5: Проработка мобильного интерфейса**.

```
project/

├── styles/
│   ├── style.css          # Основные стили (десктоп)
│   └── mobile.css         # Мобильные стили
```

## ✅ Реализованные функции

### 1️⃣ Адаптивное меню (Desktop → Tablet → Mobile)

**Desktop (>768px)**
- Горизонтальное меню в шапке сайта
- Hover-эффекты с изменением фона
- Кнопка CTA "Заказать"

**Mobile (≤768px)**
- Гамбургер-меню с анимацией
- Боковая панель навигации справа
- Затемнение фона (overlay)
- Блокировка скролла страницы

### 2️⃣ Sticky-навигация
- Меню фиксируется вверху экрана при скролле
- Автоматически скрывается при прокрутке вниз
- Появляется обратно при прокрутке вверх
- Остается видимым при открытом меню

### 3️⃣ Кнопка "Наверх"
- Появляется после прокрутки на 300px
- Плавная прокрутка к началу страницы (smooth scroll)
- Адаптивный размер:
  - Desktop: 56×56px
  - Mobile: 52×52px
- Анимация при наведении и нажатии

### 4️⃣ Дополнительные фичи
- Активная ссылка меню при скролле к секции
- Плавное появление карточек товаров
- Ripple-эффект при нажатии на кнопки
- Закрытие меню клавишей Escape
- Автозакрытие меню при изменении размера окна

## 🎯 Ключевые CSS-техники

### Responsive Grid Layout
```css
.combo-grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 40px;
}

/* Mobile */
@media (max-width: 768px) {
    .combo-grid {
        grid-template-columns: 1fr;
    }
}
```

### Sticky Header с автоскрытием
```css
.header {
    position: sticky;
    top: 0;
    transition: transform 0.35s ease;
}

.header--hidden {
    transform: translateY(-100%);
}
```

### Гамбургер-анимация
```css
.menu-toggle.active .menu-toggle__line:nth-child(1) {
    transform: rotate(45deg) translate(6px, 6px);
}
```

### Touch-зоны
```css
.btn, .link {
    min-width: 44px;
    min-height: 44px;
}
```

## 🚀 JavaScript функционал

### Управление меню
```javascript
function toggleMenu() {
    menuToggle.classList.toggle('active');
    mainNav.classList.toggle('active');
    navOverlay.classList.toggle('active');
    document.body.style.overflow = mainNav.classList.contains('active') ? 'hidden' : '';
}
```

### Скрытие header при скролле
```javascript
if (currentScroll > lastScroll && currentScroll > 100) {
    header.classList.add('header--hidden');
} else {
    header.classList.remove('header--hidden');
}
```

### Кнопка "Наверх"
```javascript
scrollTopButton.addEventListener('click', () => {
    window.scrollTo({
        top: 0,
        behavior: 'smooth'
    });
});
```

## 🧪 Тестирование

### Desktop (Chrome, Firefox, Safari)
1. Откройте сайт в браузере
2. Проверьте горизонтальное меню и hover-эффекты
3. Прокрутите страницу - header должен скрываться/появляться
4. Проверьте появление кнопки "Наверх" после прокрутки
5. Кликните на кнопку "Наверх" - должна быть плавная прокрутка

### Tablet & Mobile (DevTools)
1. Откройте DevTools (F12)
2. Включите режим адаптивного дизайна (Ctrl/Cmd + Shift + M)
3. Выберите iPhone, iPad или другое мобильное устройство
4. Проверьте:
   - Гамбургер-меню открывается/закрывается
   - Затемнение фона при открытом меню
   - Блокировка скролла страницы
   - Размеры touch-элементов (≥44px)
   - Кнопка "Наверх" работает корректно
   - Меню закрывается всеми способами
